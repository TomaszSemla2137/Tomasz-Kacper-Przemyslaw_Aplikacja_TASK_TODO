# -dopaminowe-kasyno-ADHDowców-w-Aplikacja-mobilna-z-listami-zada-i-systemem-nagradzania-u-ytkownika
**NPI projekt zaliczeniowy**

Aplikacja powinna zawierać interfejs wizualny z paskiem postępu i listą zebranych punktów, wyświetlanie zadań na pasku powiadomień, informować twórcę zadania że zostało ono wykonane oraz oferować zadania czasowo-cykliczne których nie wykonanie będzie skutkowało ujemnymi punkami, kolejne progi punktowe odblokowują nowe awatary (oraz może w przyszłości zmiany wizualne interfejsu)
